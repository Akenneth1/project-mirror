# Source Register — V2

## Hiérarchie des registres

Ce registre général est la source canonique de gouvernance des sources pour PROJECT MIRROR : il définit les métadonnées requises, les niveaux de confiance et les règles de vérification.

`docs/g0-g3/source-register-g0-g3.md` est un sous-registre de travail limité aux documents G0–G3. Ses identifiants `SRC-G0G3-*` restent stables et servent aux citations locales de ce paquet ; ils ne remplacent, ne renomment ni ne dupliquent les identifiants de ce registre général.

Lorsqu'une source du sous-registre est déjà présente ici, la fiche générale existante demeure la référence de gouvernance. Lorsqu'elle n'y figure pas encore, elle doit être ajoutée ici avec les métadonnées obligatoires avant toute décision importante fondée sur elle, sans modifier l'identifiant `SRC-G0G3-*` déjà cité dans G0–G3. Le sous-registre reste alors un index de cadrage, non une seconde source canonique.

## Métadonnées obligatoires
- SRC-ID
- titre
- auteur/organisme
- URL
- date de publication
- date de consultation
- type
- pays/périmètre
- population
- affirmation soutenue
- passage précis
- niveau de confiance
- limites
- documents dépendants

## Niveaux
A = officiel/primaire
B = académique
C = secondaire fiable
D = observation utilisateur
E = hypothèse/non vérifié
