## 2. Modèle recommandé pour MIRROR

### Phase 1

Objectif :
valider l'utilité, pas maximiser le revenu.

Modèle :
- accès gratuit limité ;
- nombre limité de générations ;
- pas de paiement obligatoire au premier test.

### Phase 2

Freemium :

Gratuit :
- profil ;
- quelques try-ons ;
- historique limité.

Premium :
- générations plus nombreuses ;
- garde-robe avancée ;
- styling ;
- comparaison ;
- historique ;
- fonctions avancées.

### Phase 3

Affiliation / commerce :

Lorsque la confiance est établie :
- liens marchands ;
- commissions ;
- produits similaires ;
- alertes de prix.

### Phase 4

B2B :

- API ;
- SDK ;
- widget ;
- abonnement SaaS ;
- tarification à l'usage.

## 3. Principe

Ne pas monétiser une fonctionnalité avant de prouver qu'elle crée une valeur répétée.
