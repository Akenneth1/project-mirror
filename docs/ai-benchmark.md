# AI Benchmark — V2

## Objectif
Sélectionner une solution VTO selon qualité, robustesse, coût, latence, licences et données.

## Périmètre

Le benchmark MVP couvre uniquement les catégories canoniques définies dans `input-contract.md` et `g0-g3/g2-ai-benchmark.md` : t-shirts, chemises et hauts simples. Les sweats simples et vestes légères ne sont pas supportés dans le MVP ; ils ne peuvent être évalués qu'en exploratoire, sans effet sur le périmètre produit.

## Solutions
Comparer APIs commerciales, modèles open source compatibles, auto-hébergement et fournisseurs spécialisés.

## Qualité
- fidélité couleur ;
- motifs ;
- forme ;
- matière visible ;
- identité ;
- silhouette ;
- artefacts.

## Robustesse
Poses, morphologies, teints, âges adultes, qualité d'image, vêtements complexes.

## Opérationnel
API, quotas, disponibilité, suppression, région, entraînement éventuel sur données client.

## Juridique
Licence, usage commercial, modification, redistribution, restrictions.

## Économie
Taux de succès, p50/p95, coût/génération, coût/résultat utile.

Aucune solution ne doit être choisie sur quelques images « impressionnantes ».
