# Feature Library — V2

## Niveau 0 — Validation/MVP
Session, photo, vêtement, validation, analyse, try-on, contrôle qualité, résultat, régénération, sauvegarde, historique minimal, feedback, suppression.

## Niveau 1 — Après validation
Profil morphologique avancé, préférences de style, wardrobe progressif, comparaison de looks, recommandations simples.

## Niveau 2 — Expansion
Import URL, navigateur, shopping contextualisé, seconde main, coût par port, packing, recommandations avancées.

## Niveau 3 — B2B
Widget « Try on me », API, SDK, analytics marchand, intégration catalogue.

## Niveau 4 — Exploration
Vidéo, avatar 3D, social, marketplace.

La présence d'une fonctionnalité dans cette bibliothèque ne vaut pas approbation de développement.
