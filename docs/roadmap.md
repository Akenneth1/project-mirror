# Roadmap — V2

## Phase 0 — Consolidation
Cohérence MVP/PRD/features/gates/sources.
**Gate :** aucun conflit critique.

## Phase 1 — Validation utilisateur
Entretiens, prototype, concierge VTO, mesures.
**Gate : G1.**

## Phase 2 — Benchmark IA
Dataset, protocole, benchmark, licences, données.
**Gate : G2.**

## Phase 3 — Prototype automatisé
Reproduire la valeur sans intervention humaine.
**Gate : G3.**

## Phase 4 — MVP
Expérience reproductible avec sauvegarde, historique, feedback et suppression.

## Phase 5 — Rétention
Démontrer une répétition d'usage.

## Phase 6 — Économie
Démontrer une économie unitaire compatible.

## Phase 7 — Expansion
Wardrobe, shopping, import URL, recommandations, B2B/API.

Aucune phase ne doit être engagée uniquement parce que la précédente est « terminée » : le gate correspondant doit être documenté.
