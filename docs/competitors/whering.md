# Analyse concurrentielle — Whering

## Positionnement

Whering se positionne comme une application de garde-robe numérique, de styling et de découverte sociale.

Le site officiel indique plus de 10 millions d'utilisateurs.

## Fonctionnalités documentées

- import depuis photo ;
- suppression de fond ;
- base de plus de 100 millions d'articles selon Whering ;
- import depuis des sites retailers ;
- extension navigateur ;
- organisation du dressing ;
- recherche et filtres ;
- suggestions quotidiennes ;
- planification ;
- packing ;
- statistiques ;
- cost-per-wear ;
- fonctionnalités sociales.

Sources :
- https://whering.co.uk/
- https://whering.co.uk/faq/price-of-item
- https://apps.apple.com/fr/app/whering-garde-robe-virtuel/id1519461680

## Force produit

Whering montre qu'une garde-robe numérique peut devenir un produit à part entière et pas seulement une fonctionnalité secondaire.

## Friction potentielle

Le problème structurel du modèle est l'effort nécessaire pour constituer et maintenir une garde-robe.

### Opportunité MIRROR

Réduire la friction grâce à :
- import automatique ;
- reconnaissance de vêtements ;
- import depuis photos existantes ;
- ajout progressif ;
- utilisation immédiate avant même d'avoir une garde-robe complète.

## Leçon stratégique

Ne pas demander :

> « Numérisez tout votre dressing avant de commencer. »

Mais :

> « Ajoutez seulement ce dont MIRROR a besoin maintenant. »
