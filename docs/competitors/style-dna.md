# Analyse concurrentielle — Style DNA

## Positionnement

Style DNA combine personnalisation, analyse du style, recommandations, garde-robe et assistant de shopping.

## Fonctionnalités documentées

L'application et sa documentation indiquent notamment :
- analyse à partir d'un selfie ;
- analyse du type de corps ;
- hauteur et mesures ;
- préférences ;
- garde-robe ;
- génération d'outfits ;
- « item match check » ;
- recommandations ;
- assistant IA ;
- personnalisation du shopping.

Sources :
- https://styledna.ai/
- https://styledna.ai/privacy-policy
- https://apps.apple.com/us/app/style-dna-ai-stylist-closet/id1358319821
- https://play.google.com/store/apps/details?id=style.dna.app

## Leçon produit

Style DNA montre la valeur potentielle de l'analyse de style et de la garde-robe.

## Risque

Une collecte trop importante de données peut augmenter la friction et les préoccupations de confidentialité.

La politique de confidentialité de Style DNA indique notamment l'utilisation de photos, données corporelles, taille, mesures et préférences pour personnaliser le service. Elle décrit aussi l'utilisation de fournisseurs cloud et des transferts internationaux sous certains mécanismes juridiques.

## Opportunité MIRROR

Créer un système progressif :

Niveau 1 :
- photo ;
- vêtement.

Niveau 2 :
- préférences.

Niveau 3 :
- garde-robe.

Niveau 4 :
- mesures facultatives.

## Principe

La personnalisation doit être gagnée progressivement par la valeur fournie, et non exigée dès le départ.
