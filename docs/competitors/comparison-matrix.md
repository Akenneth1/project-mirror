# Competitor Comparison Matrix — V2

## Méthode
Toute cellule doit être sourcée ou marquée `Non vérifié`.

## Axes
Proposition de valeur, cible, entrée, catégories, VTO, wardrobe, styling, shopping, import URL, extension, social, B2B/API, onboarding, modèle économique, disponibilité, traitement des données, frictions observables, source, date de vérification.

## Concurrents prioritaires
Doji, Google, Whering, Style DNA, DREZI et fournisseurs/API VTO commerciaux.

L'analyse sert à distinguer ce qui est commoditisé, les attentes et les frictions. Une fonctionnalité concurrente n'est pas automatiquement une fonctionnalité MIRROR.
